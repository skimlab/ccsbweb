# Abstract

Text-to-SQL aims to convert natural language questions into executable SQL queries for retrieving information from relational databases. However, geospatial databases present unique challenges due to complex spatial data types, coordinate reference systems, and geometric predicate functions. In this paper, we present a comprehensive case study evaluating Large Language Model (LLM)-based Text-to-SQL frameworks for geospatial information retrieval. We design specialized schema-linking, in-context prompt engineering, and iterative syntax-correction mechanisms to bridge natural language spatial queries and PostGIS dialect requirements. Extensive evaluations show that the proposed methodology significantly improves query generation accuracy and schema comprehension in geospatial decision-support systems.
